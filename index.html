This public site is static HTML on GitHub Pages (branch main, repo root). Default URL: tranquil-freelance.github.io/RENEET. No custom domain is configured in this repository.

The full interactive product — OMR exam flow, AI SWOT, Razorpay, daily check-ins — lives in the Next.js application in the same repository (app/, /api/*). That code does not execute on GitHub Pages (no server, no API routes). To run it, clone the repo and use your own machine:

  • git clone this repository
  • npm install then npm run dev
  • Copy .env.example to .env.local and add keys when you are ready
